## Usage

These tools facilitate creating Auro-compatible .keg packages:
- `kegmake`: Generate a package from a source project
  Example: `kegmake /path/to/project`
- `kegbuild`: Build a package from existing sources
  Example: `kegbuild /path/to/source`
- `kegify`: Package a binary into .keg format
  Example: `kegify mybinary`

Documentation includes installation instructions and full usage examples in the tools' source code.
